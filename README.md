# Team Notes

A community Blend for [acrylblends](https://acrylblends.github.io): a multi-user notes app (sign-up, log-in, search, SQLite with migrations) that opens in a desktop window or in the browser.

It is a test repository, made to rehearse how a Blend published in its own repository is listed on acrylblends.github.io/blends: it has the topic `acrylblends-blend`, a `blend.yaml` with `visibility: public` and a licence, and a tag.

```bash
npm create acrylblends@latest my-notes -- --from github:inboxxobni/team-notes#v0.1.0
```
